What it is not.

This category has a history of losing developer trust. So the boundaries are part of the product.

×Not a code reviewer

It does not read your diff for style

Reviewers check code against code. Groundtruth checks the running app against the claim you wrote. Keep your reviewer.

×Not a test suite

It does not need your tests

No existing suite, no visual baseline, no recorded traffic. The oracle is the description itself, so it works from the first PR of an empty repo.

×Not a wall of green

It does not fake confidence

When a claim needs a signed-in session, you get an honest "could not verify" with the reason, not a hopeful pass.

We check what you meant to change.
And what you didn't.

One YAML block. The first verdict lands on your next pull request.
